# v0.2 算法与验证预设

配置冻结于首次压力实验运行之前（2026-10-14）。

- 同时比较 OLS、原版唯一单星 FDE、最小故障数多假设一致性、受 SAC-GNC 启发的自适应 GM 连续化。
- 新算法最多剔除两星，至少保留 5 星，一致性 alpha=0.001、sigma=1 m、非加权 PDOP 上限 30。同一最小剔星数多个假设通过则 SUSPECT，不根据真值选解。
- GNC 使用 1.4/2.6/4.9 三种退火速率、宽度 3、深度 6、每分支最多 5 次 IRLS、3 sigma MSAC 截断。其权重用于假设排序，最终仍需无权子集验证。
- 开发种子 20261014；独立验证种子 20261015；保留种子 20261016。保留种子结果公布后不据此调整配置并继续称其“未见测试”。
- 每种子 7 类 × 84 历元：正常、单星、渐变、双星、共同偏差、重尾噪声、噪声先验失配。均基于相同课程 D02 几何，不能等同未见轨迹/真实多路径。
- 位置误差、位置可用率、10 m 联合成功率、强故障召回、错剔率、SUSPECT/有效状态比例、P95 耗时同时报告。
- 默认选择受课程回归和上述对照证据约束。前沿模型没有改善时保留实验选项，并公开代价与失败案例。
