# 第四轮：弱故障时序检测与四星初始化恢复

本轮改动已写入项目，普通解及教师输入输出接口保持不变。**最终独立数据中的六星连续冷启动、快速换星汇总指标通过，但冷启动最初10历元、孤立首历元、部分具体星组仍失败，不能称为六星全面达标。** 四星/五星增加了检测边界和恢复处理，也没有把缺少冗余的问题伪装成准确定位。

## 修改与依据

1. `core/temporal.py`增加短窗奇偶空间检验。每个历元独立消去XYZ与钟差，仅对候选单星偏差的短时线性变化估计两个参数；没有接收机静止、恒速、固定高度或历史坐标约束。普通全局检验没有触发时，也能利用弱而持续的残差证据。该投影回归与独立构造的整块观测最小二乘逐项比对，覆盖4种观测数量和每历元任意改变的接收机增量。
2. 继续使用原有16历元、5秒最大间隔、0.001名义假警概率。多个候选及窗口分配检测预算；只有当前残差也支持异常才触发，避免故障消失后仍靠旧窗口报警。选取满足残差一致性和一步预测创新检验的最长后缀；集合变化、时间中断、时间倒退、观测不足会清空证据。时序候选只补充未越过单历元门限的弱证据，已越限的判别保持原有逻辑。
3. 每个剔星候选仍须通过**当前历元**的残差、几何及冗余检查。确认身份和暂定位置分开；相对证据不足仍为SUSPECT。20:1是工程选择分数，不是经校准的正确概率。有限窗口的线性偏差假设、相关噪声及反复使用历史均限制理论假警解释，以下实际误报必须同时阅读。
4. 新增逐星可观测性诊断：残差冗余、给定名义噪声/单历元检验下达到90%检测概率所需的偏差幅度。它是条件分析，不是保护水平。四星明确无冗余；五星发现不一致后保持SUSPECT、不猜测故障身份。检测与排除所需冗余不同，参见 [ESA RAIM](https://gssc.esa.int/navipedia/index.php/RAIM)。
5. `core/initialization.py`增加由当前伪距求代数初值的失败恢复。方法依据 [Bancroft的平方伪距方程](https://gssc.esa.int/navipedia/index.php/Bancroft_Method)。**只在改进解的原迭代失败后启用**，代数近似不是最终解；仍须用原完整物理模型收敛，重新检查3°截止角、未加权PDOP和四未知数可解性。没有有效初值则保持无效；所有可用初值均呈差几何且完整迭代失败时，记录依据并输出INVALID_GEOMETRY。普通解及其下一历元初值不受此恢复分支改变。

没有引入卫星专属参数、测试故障时间表、真值、未来观测，或上一位置替代当前解。新增CLI消融开关：`--disable-temporal-parity`、`--disable-algebraic-recovery`；两者同时关闭可对照第三轮默认方法。

## 独立验证设计

先制定[验证计划](diagnosis-iteration4-plan.md)，再冻结代码和参数。前三轮所有数据仅作为开发回归。第一批独立种子622261—622267发现四星初值问题，保留全部结果；补充恢复后，另行预设622271—622277并重新冻结，最终验证后未再修改数值代码。

最终8组共**107,779个输入历元**，每个输入分别运行上轮和本轮方法：六星连续15,680、孤立首历元336、高噪声15,680、七星4,480、可见集合变化560、四星39,200、五星31,360、星数变化/中断483。覆盖全部70种四星、56种五星、28种六星、8种七星子集。前向生成新的位置、运动、钟差、噪声、故障与正负号，不读取D02观测；共享教师星历及已验证的物理改正函数。因此是新的受控仿真，不是外场或教师隐藏数据。

每组保存完整输入、真值、双解CSV、逐星诊断、逐历元评价、失败清单、配置及源码/输入哈希。真值仅在生成和事后评价使用。四/五星几何分类事先根据真值几何定义，未依据求解精度筛选；原始所有历元和教师要求输出位置的分母同时保存。报警率、正确标星率、确认正确率分开。

最终六星正常/共同偏差P95分别2.263/2.217m，均100%可用，误报0。连续流所有场景合计P95=3.416m、10m成功率98.07%。这些汇总不能覆盖表中失败的启动窗口。

与同一新输入上的第三轮比较，快速换星强故障段P95 **6.100→5.388m**，10m成功率 **95.48%→96.25%**，正确标星率 **95.48%→96.43%**；错剔53→55，确认错剔均为0。连续冷启动段本批反而略退步：强故障P95 5.471→5.750m，成功率96.01%→95.77%；确认错误仍有2个。全六星错剔251→262，确认错误仍为2个。新增检测提高覆盖，也增加了一些错误暂定选择，并非所有指标单调改善。

进一步按具体星组分开，28个冷启动连续场景中3个未同时满足故障P95/成功率/标星率；28个快速换星场景中7个未同时满足。第一批新数据的快速换星强故障P95为26.216m，仍失败，结果未被删除。最终批汇总通过不等于跨几何稳定通过。旧开发回归中，六星冷启动整体P95从20.335降到18.777m，也仍不达标。

孤立首历元没有历史，本轮时序方法不会改变它，29次错误暂定剔除全部为SUSPECT，确认错误0。冷启动最初10历元在最终批也没有改善。近共线的故障方向及极低故障可观测性仍是主要限制；前轮保留的[双状态不可辨识构造](../runtime/diagnosis-iteration3/cold-identifiability.json)说明不能保证任意六星首历元达标，但不替代本轮实测失败。

| 六星可见集合每12历元变化 | 全部P95=2.677m，强故障P95=3.790m、成功率99.56%，错误剔除0 | 只有560个历元，第一批集合变化仍有失败 |

最终四星失败恢复共触发249次：231次完整模型重新收敛并给出几何警告，12次给出有依据的INVALID_GEOMETRY，6次仍不收敛。恢复出的警告位置均属于预定义极差几何；其大误差使包含所有警告位置的原始P95升高，因此不能将“输出更多警告位置”称为精度提高。教师要求输出位置集合的P95不受这一变化影响。6个剩余失败的历元、原因和全部诊断已存入checks.json，没有用真值强制改状态。

高噪声压力（实际2.4m，教师名义模拟为0.8m）仍未通过：总体P95 23.523→21.117m，10m成功率89.01%→89.97%；无故障状态误报3.84%→4.59%，错剔1050→1160，确认错剔140→146。阶跃/渐变场景的短纯净段误报分别约10.18%/12.86%。不能只引用整体误报低于5%就称压力测试通过。

## 复现

使用空输出目录，运行会拒绝覆盖已有证据：

```sh
uv run python scripts/validate_six_satellite.py --comparison iteration4 --suite continuous --seed 622271 --out runtime/recheck-six-v4
uv run python scripts/validate_six_satellite.py --comparison iteration4 --suite four --seed 622275 --out runtime/recheck-four-v4
uv run python scripts/validate_six_satellite.py --comparison iteration4 --suite five --seed 622276 --out runtime/recheck-five-v4
uv run gnss solve --input YOUR_INPUT.jsonl --out runtime/ablate-v4 --disable-temporal-parity --disable-algebraic-recovery
```

其他suite/种子见冻结清单。默认开启本轮改进，`--disable-fde`仍完全关闭改进处理。所有新结果和未达标细分保存在runtime/diagnosis-iteration4，未更新交付包、展示报告或演练材料。
