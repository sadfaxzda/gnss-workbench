# 第五轮改进与验收计划

继续遵守教师单历元四未知数、独立普通等权解、当前/过去观测、原JSONL/TCP/十四列CSV。第四轮所有数据仅作开发回归，不将重复回放称为独立验收。

本轮首先修复两类机制问题：

- 换星：单历元证据不足时，原窗口可能继续被旧身份支配。增加多个可能变化时刻与新身份的累积似然比较，分摊候选/变化时刻数量，只有当前证据支持新身份才截断旧证据；不引入指定换星间隔。
- 极差几何：原代数初始化只保留模型域内实根，无法解释复根或域外根对应的严重病态。将近似候选用于失败诊断，最终位置仍必须通过完整物理模型迭代、地表模型域、高度角及几何检查，不把近似根当定位输出。

不改变名义噪声、20:1证据比、16历元长度或教师评分门槛。未见测试前冻结参数和源码；通过/失败、全部星组、错误标记、错误确认、状态及可用率一并保存。新增独立种子预设：623281连续六星，623282孤立六星，623283噪声压力，623284七星/集合变化，623285四星，623286五星，623287星数变化/中断。新增不规则换星/随机游走偏差及采样变化独立种子623288，避免只适应原来固定15历元的故障段。

任务书要求准确表达不可辨识情形，故四星故障修复、五星唯一归因、任意六星首历元精度不得虚构保证。任何修改后的最终验收必须使用未见种子；不按失败结果筛选、删除、改写真值或放宽阈值。
