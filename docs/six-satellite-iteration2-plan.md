# 六星诊断第二轮预设方案

2026-10-16，在新增独立验证运行前记录。既有的全部D02派生验证现视为开发/回归资料，不能再次称为独立验证。

本轮不改变等权普通解、课程观测模型、JSONL/TCP或14列CSV。先开发和检验两个机制：

1. 全局异常、多个剔星假设均通过时，允许用最大似然的当前子集提供暂定改进解，但保持SUSPECT、明确身份待确认，绝不把相对似然份额当作正确概率。只标记并实际剔除一个最优候选，不通过标记全部候选提高检出率。确认仍需要原有证据门槛，另报告“正确暂定/确认归因”“确认覆盖率”“错剔”和真值位置误差。若新机制增加错误，须明确报告，不能删除失败历元。
2. 在当前残差检验以外，比较历史领先身份在相邻历元的带符号故障幅度估计。按几何冗余推导幅度方差，结合当前候选残差组成卡方创新统计量；超限即重置历史。使用已有sigma和Pfa，不根据测试结果选新阈值。不缓存接收机位置约束，不使用未来或真值。

开发包括既有冷启动和换星反例。最终验证参数在开发结束后冻结：种子621031（连续）、621032（孤立冷启动）、621033（噪声失配压力）；生成新的轨迹、钟差、噪声和故障，采样不同配套星历有效时刻及附近不同接收机位置，覆盖全部28种六星子集，正负偏差、从首历元故障、直接换星、阶跃/渐变、共同偏差、正常恢复与断续。生成器按课程模型从轨迹正向合成伪距，不叠加D02观测，不向解算器提供合成真值。仍共享给定广播星历和物理改正函数，不声称独立外场验证。

指标按情景分别报告，不以正常段稀释故障指标；每个输入历元计入可用率和10m内联合成功率。记录旧版、新版、仅暂定解、仅创新重置的消融，保存所有输入、标签、逐星证据、普通/改进CSV、代码/输入哈希和完整失败样例。不根据最终验证结果反复修改参数；如果发现实现缺陷，保留旧结果并重新预设新种子。

相近故障方向下，单历元六星可能无法可靠区分身份；本轮目标是减少不必要的漏检和错误历史，争取课程指标，不能承诺任意几何都满足精度和识别要求。

开发阶段补充：暂定子集解使“当前最优与历史最优不一致”时无需退回污染的普通位置。因此新版确认门槛额外要求当前最优与历史最优一致，分歧时仅给暂定SUSPECT。该一致性检查与幅度创新重置同属fde_change_detection消融开关。旧数据上的直接换星开发对照须同时报告暂定误选增加和确认误判减少；这是覆盖率与确认可靠性的显式取舍，不视为每一个错误都已修复。此修订在621031/621032/621033运行前固定，既有sigma、Pfa、20:1及16历元保持不变。

开发中还验证了确认与位置选择必须分别处理：当前最小残差受噪声短暂跳动时，不能把已有充分历史证据的暂定位置直接换成另一个当前候选。最终暂定位置优先使用仍通过当前检验、累计相对似然达到原20:1且无当前强反证的历史候选；否则使用当前最大似然候选。当前与历史不一致时只降低确认状态，不强迫换到当前最小值。该规则在最终独立集开始前冻结。
