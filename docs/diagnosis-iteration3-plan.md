# 本轮算法验收约束

范围：修复噪声失配导致的误报、复查单星确认与换星历史、补齐独立数值与接口验证；不修改普通等权解、教师输入或十四列 CSV，不做交付包和展示改动。

开发数据为前两轮全部已见数据。新方法只使用当前和过去观测，不读取真值，不设置卫星身份、接收机位置、高度或故障幅值先验。噪声估计使用不重叠历元对的全星奇偶空间差分，禁止用挑选出的最小子集残差估计噪声，以免选择偏差。故障和恢复也必须进入估计器测试。改进位置仍由当前历元保留观测独立拟合。

拟验证的新种子预设为 621141（连续）、621142（孤立首历元）、621143（噪声失配）、621144（七星及观测集合变化）。开发结束后冻结源码与配置，再运行以上集合；若失败，保留全部结果，不在同一集合上调参后宣称独立通过。指标按场景、强故障段及全部历元分别计算，正常段不稀释故障失败；确认错误与暂定错误分开计数。高噪声压力超出教师 0.8 m 噪声模型，单独列出，不与课程精度验收混合。

单历元六星的近共线故障方向可能产生几乎相同的伪距分布。不能靠把全部候选标异常、删除难历元或把暂定结果升级为确认来达到检出率。若信息不足，必须保存候选分离证据和限制。

第一阶段独立结果全部保留在 `runtime/diagnosis-iteration3/independent-*`，对应 `phase1/frozen-code.json`。其中六星频繁换星 hP95 为 19.93 m，未通过；噪声误报已改善。分析表明，许多错误发生在没有强反证但累计证据尚不到确认门限时：选择器退回逐历元最小残差，抛弃了仍有价值的弱历史。

第二阶段将“选择暂定条件解”与“确认身份”进一步分开：若当前没有强反证，历史领先子集仍通过当前检验，可用于暂定位置，无须先达到确认门限；确认门限、断续/换星重置、当前残差/几何条件保持。该阶段开发使用此前所有已见集合，最终新种子预设为 621151/621152/621153/621154，分别用于连续/孤立/高噪声/七星及集合变化。冻结后再验，保留第一阶段失败，不把它重新称作未见验证。
