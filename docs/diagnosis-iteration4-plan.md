# 第四轮改进与独立验收计划

用户范围：继续改善六星冷启动、快速换星；检查四星、五星；普通独立等权解、教师JSONL/TCP/十四列CSV不变。前三轮所有数据只作为开发/回归数据。

拟改进机制：现有逐历元全局门限会丢弃弱而持续的故障证据；逐历元自由估计故障幅度也浪费了时间上的一致性。新增有限窗口的奇偶空间时序检验，每历元仍消去独立XYZ/钟差，只对单星偏差的短时线性变化建模。不把历史位置当约束。用一致性和当前预测创新约束窗口，避免跨换星混合证据；与单历元检验并行，候选仍须通过当前子集检验。多窗口检测必须分摊假警预算，不能直接把累积残差与单历元门限比较。暂定选择与身份确认分开。

四星在满秩时无残差冗余，继续标明NO_REDUNDANCY，不宣称故障可检测。五星可以检测不一致，剔一星后没有验证冗余，不能把四星拟合的零残差当作故障确认。新增明确的可观测性证据和独立覆盖测试，而非填入上一位置或任意猜测故障卫星。

开发结束冻结算法/参数/生成器。独立种子预设：622261六星连续，622262孤立六星，622263高噪声，622264七星及集合变化，622265四星，622266五星，622267数量变化与时间中断。覆盖全部四/五/六/七星子集、正负偏差、启动故障、渐变、阶跃、快速换星、共同偏差与恢复。逐场景和强故障段分别统计，全部失败保留。四/五星的报警率和正确身份率分别记录，不能用SUSPECT冒充已定位故障。更换参数后旧独立集视为开发数据，必须另设未见种子复验。

冻结决定：仅保留两参数（偏差、漂移）的线性短窗检验。常数/线性模型选择在开发回放中没有改善，未进入最终算法。时序候选只补充未越过单历元全局门限的弱证据；已经越限时继续采用原有独立子集判别。新增监测器采用原有16历元/5秒间隔与0.001假警配置，未为具体卫星、故障段或测试集设置参数。单次检测预算按候选数与窗口数分配；历史重用和模型失配下的误报须用实测结果评价，不能宣称其为安全保证。

冻结后运行以下预设8组（七星与可见集合变化共享预先指定的622264，各自生成完整输入），不因结果好坏筛选星组。四/五星和数量变化组按预先定义的真值几何分类，另外保留原始所有历元统计；无位置和极差几何状态不得混入正常精度分母。统计同时给出：所有有效位置P95与可用率、强故障段P95/10m成功率、正确标星/确认身份、错误剔星/错误确认、纯净段标星误报/状态报警。不能用总体平均掩盖失败分段。

第一批独立结果暴露四星极差几何初始化问题：196个严格状态不匹配，其中194个原迭代不收敛、1个错误分支落到截止角以下、1个观测噪声使PDOP跨越30阈值。追加仅改进解失败路径的当前伪距代数初值恢复，必须通过原完整模型迭代与高度角/几何检查后才输出位置；普通解及其初值不改。没有可用初值时保持无效，不用真值改写几何状态。新增独立平方伪距构造测试（4—8星、任意位置、正负钟差）与普通解隔离/观测不足边界测试。

因此第一批622261—622267全部保留，但不再称为最终版本的未见验收。第二次冻结后预设最终种子：622271六星连续、622272孤立冷启动、622273高噪声、622274七星与集合变化、622275四星、622276五星、622277星数变化与时间中断。六星时序判别参数不因第一批数值结果调整。最终测试后不再调参或筛选场景，失败照实记录。
