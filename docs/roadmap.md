# 迭代路线图

## v0.1：可信的完整闭环（已实现）

- 独立基线、GPS 单点定位、单星检测与剔除。
- 实时双解轨迹、逐星证据、可控故障实验、关闭 FDE 的消融对照。
- TCP 异常处理、历史恢复、可追溯输出与自动化检查。

## v0.2：让创新点有实验支持

| 方向 | 用户价值 | 完成判据 |
|---|---|---|
| 诊断回放增强 | 选中故障时刻即可解释判断 | 卫星天空图联动残差与剔星候选；导出对应证据 |
| 系统化参数扫描 | 比较检出率、误报率与精度的权衡 | 多随机种子、多个噪声水平/卫星/偏差幅度，自动生成实验矩阵 |
| 稳健噪声与加权估计 | 改善非均匀观测噪声的表现 | 与等权基线、仅加权、仅 FDE、组合方案做同输入消融；不破坏规定的基线 |
| 多故障与渐变故障边界 | 展示方法何时有效、何时需要拒绝判断 | 双星、多星和缓变故障测试；明确不可辨识情形和退化策略 |
| 一键生成实验报告 | 减少人工摘录数字造成的错误 | 从运行产物生成图表、参数、哈希及算法说明，数字可追溯到原始 CSV |

上述为计划，尚不宣称实现。统计方法本身采用已有理论；课程创新重点是可交互、可解释、可复现的定位诊断实验系统，以及通过消融实验验证的改进。

## v0.3：扩展数据与交付方式

- JSONL/导航文件导入、格式校验与预览，替代当前网页内置三份数据的限制。
- 更长数据流的分页查询、按时间索引、分块传输及图表降采样。
- WebSocket 全量类型生成，运行数据清理策略，配置化打包与容器构建验证。
- 在已验证的需求下评估 Tauri 桌面封装或受保护的服务器部署。
