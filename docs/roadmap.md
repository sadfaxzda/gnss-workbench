# 迭代路线图

## v0.2 已实现（2026-10-14）

- 保留等权 LS 与 v0.1 单星 FDE，对照新增最多两星的最小故障数一致性诊断。
- ICCV 2025 SAC-GNC 启发的 GM 自适应连续化实验模式、搜索轨迹与提议权重；最终仍需独立子集验证。
- 三个固定种子、七类压力场景、四种配置，共7056次方法-历元比较；一条命令生成CSV/JSON/Markdown实验报告。
- gnss_lib_py 可选独立 WLS 交叉校验。
- 网页导入自定义 JSONL/导航、卫星天空图、算法切换、坏观测历元隔离。
- TCP 过期历史状态跨刷新保持；只有新历元可恢复当前位置有效性。
- 课程要求矩阵、6页技术报告草稿、成功与失败案例和原始保留实验归档。

## v0.3：由失败证据推动

1. 噪声尺度与异方差估计。先做仅使用过去历元的独立标定集，再用新的封存数据验证，避免根据测试集改 sigma。
2. 新几何与独立真实轨迹。当前压力测试沿用 D02，不能代表真实城市峡谷；D01 缺独立真值。
3. 真正的多方法 benchmark。接入 gnss_lib_py EDM FDE、GNC-TLS、Cauchy/Huber 基线；统一数据、改正、运行环境和可用率口径。
4. 当前有限搜索最多两星；更高故障率需要明确新的可观测性条件，不能无节制剔星获得低残差。
5. 长数据的分页/降采样，完整 WebSocket 事件代码生成，轮转清理与部署打包。

## 提交前仍由真实成员完成

- 填写成员姓名、实际贡献与提交记录，每人能解释观测模型、状态和一次失败案例。
- 完成最终演示/答辩和教师隐藏用例。当前测试通过不等于未知测试全部通过。
- 将报告草稿中的人员栏和最终运行/版本信息核验后再作为课程提交材料。
