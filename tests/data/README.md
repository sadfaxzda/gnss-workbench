`weak_unique_subset.jsonl`：上一轮已见开发数据，种子 621031，`set04-06-rapid` 的第 25 历元。独立前向生成，使用课程广播星历；未引用 D02 观测。只有 G07 子集通过绝对门限，但相对全部其他假设的对数似然比约 2.488，低于 ln(20)。用于检验不能把“唯一通过”直接等同“身份确认”。解算测试不读取真值。此反例不计入本轮独立验收。

`coherent_proposal.jsonl`: 80个独立前向仿真的六星开发历元，来自第六轮种子624291的set15-02-cold_stream。第44历元用于核验“历史证据只能调整暂定位置、不能确认身份或进入接收机初值”的机制；后续历元检查无反馈。未包含真值，属于已知开发回归，不计为第八轮新验证。
